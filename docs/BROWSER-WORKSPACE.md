# 浏览器工作区

Tanuki 使用独立 Android WebView profile，不与管理页共享 Cookie/站点存储；不是 Via 内核或 Windows 内核。实现入口为 `AgentBrowserController`、`AgentBrowserPage`、`BrowserService` 和 `BrowserOverlayWindow`；0.1.8/code10 已包含输入线程修复，**0.1.8 没有随版本记录设备测试**，本轮与历史验证边界统一见 [TEST-REPORT](TEST-REPORT.md)。RPC 方法、错误码与传输限制见 [接口契约](INTERFACES.md)。

## 授权

- AI 查看与操作分开。通过 capability 和客户端身份校验的合法工具连接可以调用 `tabs`、`snapshot`、`screenshot` 查看普通标签或当前普通页面；用户正在手动浏览、临时接管或已撤销操作权时同样可看。`status` 只返回连接元数据。
- 当前工具连接默认获准操作。触碰网页先暂停 AI 操作、使旧操作票据失效并拦截该次触摸，再询问是否收回。点击、输入、滚动、导航、前进/后退/重载、新建/切换/关闭标签，以及查找和缩放均需要操作授权。
- 「继续交给 AI」立即恢复原连接的操作权；「临时接管」期间连续 **30 秒未点击、滑动或输入**就默认交回操作权，交互重置倒计时。地址栏、原生工具栏、完整页和小窗/WebView 的触摸、键盘/输入均计入操作。
- 显式撤销 AI 操作权限持续有效，只有用户主动交回才恢复；不被 30 秒计时、切页、后台或重启覆盖。临时接管倒计时到期只重新授权同一当前连接，旧操作票据不会恢复。
- 用户自身查看浏览器始终不需要授予 AI 操作权限。DSH 页仍可通过主导航「浏览器」进入；收回操作权后仍可打开完整页或小窗、查看原页面并手动浏览。
- 切换页面、Activity 重建、后台和小窗不自行撤销操作权。导航中央（宽屏侧栏中部）的人/机器人按钮统一表示当前操作方；点击机器人明确收回操作权，点击人交回当前连接，普通页只读能力不受影响。它不是页签：拖动不切控制权，按住时镜片连续跟手、可以停在中央；只有松手仍在中央时才吸附最近有效侧，取消则回到原页签；按钮内的纵向/横向滑动也不当点击。登录保护页或浏览器不可用时禁用。
- 中央按钮直接反映实际操作权，临时接管30秒后自动恢复机器人。交回提示也随当前权限有效性更新，再次接管、显式撤权、私有页或浏览器不可用时不保留过期“已交回AI”提示，不清除下载等其他通知。
- 常态控制条已移除；待处理请求/下载、登录保护提示和临时接管询问保留。全屏、IME等隐藏主导航时沿用现有返回路径；独立小窗和通知保留本地控制入口，RPC仍不能自行授权。
- capability 和客户端身份仍须校验，不等于已证明的模型/DSH 会话身份。提交、发送、付款、删除等仍需业务确认；不保证撤回已经发出的网络请求。

## 输入线程

WebView 的 InputConnection 可在输入法后台线程回调；六种被拦截的输入操作先在主线程完成授权判断与交互计时，再在原调用线程交给 WebView。主线程直接调用不排队，后台最多等待500ms；超时或中断拒绝本次输入并取消尚未执行的判断，避免迟到接管。控制器、计时与页面状态继续只在主线程访问，不因修复输入闪退而放宽授权。主线程长时间繁忙时当次输入可能需要重试；其他输入法/机型仍需验证。0.1.8 合并了该修复；此前 22 项设备验证是历史记录，未在本轮复跑。

## 使用入口

| 功能 | 入口与行为 |
|---|---|
| 浏览/搜索 | 标题右侧紧凑输入框，首次聚焦全选、再次点击定位光标；前往箭头/键盘Go打开，搜索按已选引擎 |
| 多页 | 标题下方的叠页图标与数量角标→总览，`+`新建、卡片切换/关闭；不设固定页数上限 |
| 收藏/历史/下载 | 顶部工具栏菜单→列表，收藏支持文件夹，列表支持筛选 |
| 工具箱 | 查找、缩放、完整网页截图、页面显示模式 |
| 页面模式 | 新页默认Windows PC UA；旧标签保留显式模式。移动/Windows/Mac/Linux切换须确认重载，不更换内核 |
| 全屏 | 顶部工具栏进入；隐藏浏览器/应用导航及系统栏，右上角按钮/返回键退出；窗口始终edge-to-edge，Compose统一处理系统栏占位，避免退出后重复留白；复用WebView，不主动重载，操作进度保留 |
| 小窗 | DSH页「浏览器小窗」，用户允许系统悬浮窗后跨应用显示；顶部拖动、左右下角调大小，可收起/返回完整浏览器 |
| 操作权/后台 | 工具栏下方、分类设置和前台通知提供收回/交回操作权及停止入口 |
| 搜索引擎 | 分类设置→通用：必应、百度、Google、DuckDuckGo |

角标超过99显示 `99+`，总览和无障碍说明保留真实数量。创建、手势弹窗、记录恢复不再按12页截断；仍按需创建WebView，保留无手势弹窗拦截、协议限制及16 MiB元数据读取保护，实际容量受设备资源约束。

窄屏各页共用浮动导航，原生列表末尾预留可滚动的避让空间；原生检测到IME底部inset大于零时收起。浏览器默认让网页延伸到导航后方，不统一留白；原生前进/后退工具仍在顶部。若网页自身的固定输入框或按钮被覆盖，可在「浏览器设置→通用」开启「避让网页底部控件」，该浏览器显示偏好会保存，关闭后恢复透显。DSH仍保留上游的底部输入区避让。不抓取或重绘WebView；导航隐藏时不保留其避让，全屏复用同一WebView，宽屏保留侧栏。

## 页面、后台与数据

恢复标签先还原地址/标题，选中才加载；只让当前页活跃，已访问页保留WebView但离开绘制树。后台容器不可见、不可触摸且屏蔽无障碍焦点，小窗/完整浏览器重新挂载同一WebView，不调用全局 `pauseTimers()`。

用户启动的前台服务维持浏览与下载；系统仍可回收或限制网络，不承诺无限后台。重启可恢复地址、收藏、历史、偏好，不承诺未提交表单。系统悬浮窗权限和 AI 操作授权是两件事；撤销前者只移除小窗。

Windows PC是UA/宽视口设置，不能保证所有站点桌面布局。页面历史/偏好存于私有目录，不是无痕模式。DSH 外链在独立标签打开，管理 origin/端口和带管理 token 的地址仍被阻止。DeepSeek 官方登录使用有时限的一次性票据和专用临时标签，支持先开空白窗口再异步导航；仅将当前管理连接声明的 `/callback` 交给原生转发，其他管理导航仍拒绝。登录标签不提供 AI 读写/截图、不向 AI 列出、不存历史，完成后关闭；Cookie 不复制给管理页。真实登录尚未验收，详情见 [安全](SECURITY.md)。

## AI范围与下载

- `tabs` 只列普通标签；当前为敏感登录页时，返回的活动标签 ID 为空。`snapshot` / `screenshot` 只读取当前普通页，显式指定其他标签时返回 `tab_not_selected`，不会借查看请求切换页面；敏感页返回 `private_page`。异步读取会复核页面身份和有效期，导航或切页后的旧结果不再返回。
- 文字/控件只涵盖已加载主文档，每次最多20000字符/100控件，可按cursor继续；扫描上限50000节点并报告截断，不含未加载虚拟内容或跨origin iframe。
- 整页PNG使用完整文档绘制，不能退回小窗裁切；最大边2048px并有编码大小上限，大页面细节需要DOM/滚动辅助。改变全局绘制设置或进程边界必须重新验证尾部像素、AI缩放和收起小窗。
- 下载须原生确认，单文件上限256MiB、并发最多2个，真实字节进度与取消；未知总量不伪造百分比。下载/截图在列表中打开、经SAF导出或删除，内部以UUID寻址。
- 不自动授予上传、相机、麦克风或定位。付款/发布等另行确认。

资源回调不能证明覆盖每一跳重定向，不宣传完整网络/SSRF沙箱。真实模型、真实账号登录、HyperOS长期后台和其他系统版本仍待验收，详见 [安全](SECURITY.md) 与 [测试](TEST-REPORT.md)。

历史 AOSP 键盘合成截图中，导航显示在键盘上方，地址输入与前往按钮仍可达；证据不支持“所有键盘状态下导航必定收起”。该结果未在真实 DSH 模型任务中验收，也不是 0.1.8 的设备测试报告。
