# 原生界面功能对齐清单

本清单依据官方 DSH Web 客户端暴露的会话、对话、输入、模型、审批、工作区、设置与技能界面，以及现有 Typert Remote/`remote.mux` 协议核对；不以印象补项。目标不是把官方网页嵌进原生层，而是在原生界面复用同一官方协议逐步补齐，官方界面始终保留为可切换、可回退入口。

状态：✅ 本 PR 已实现；◐ 部分实现/有明确限制；☐ 尚未实现；— 保留官方界面，不在原生层重复实现。

## 1. 会话

| 功能 | 状态 | 说明 / 缺口 |
|---|---|---|
| 会话列表、标题、更新时间、运行状态 | ✅ | `session/list`；会话条显示运行/结束与时间 |
| 切换会话、历史重读、实时流重连 | ✅ | 选择后重读 `session/page` 并重开 `session/follow` |
| 通知点击定位会话 | ✅ | 通知目标强制选择并重连；列表失败保留目标给官方回退 |
| 会话搜索 | ☐ | 等待会话管理切片；原生页暂无搜索框 |
| 新建会话 | ☐ | 需 `session/create` 与工作区选择 |
| 重命名会话 | ☐ | 需 `session/rename` |
| 删除/归档会话 | ☐ | 官方会话管理能力，另一切片 |
| 未读/待处理交互标记 | ◐ | 当前显示运行状态与其他会话审批计数；无完整未读模型 |
| 工作区分组/排序、fork、subagent、定时任务 | ☐ | 由会话管理/工作区切片负责 |
| 会话保留/释放、Subagent 目录 | ☐ | 未接入 |

## 2. 对话与消息渲染

| 功能 | 状态 | 说明 / 缺口 |
|---|---|---|
| 历史加载 | ◐ | `session/page` 最近 120 条；`hasMore` 只提示，未做向前分页 |
| 实时流式回复 | ✅ | `session/follow` + `assistant-stream` 的 `text-delta`；落盘消息替换临时气泡 |
| 停止生成 | ✅ | `session/cancel`；状态由 `$events`/会话列表收敛 |
| 错误展示 | ✅ | 读取/实时/发送/停止/审批分别提示；短错误码，不回显响应细节 |
| Markdown 标题/段落/粗体/斜体/行内代码/列表/引用/分隔线 | ✅ | `DshMarkdown` 纯 Kotlin 解析，流式未闭合代码块按到末尾处理 |
| 代码块 + 语言标签 + 复制 | ✅ | 等宽字体、横向滚动、复制按钮 |
| Markdown 表格 | ◐ | 基础表头/单元格横向滚动；无合并单元格、对齐样式与宽表虚拟化 |
| Markdown 图片 | ◐ | 显示 alt/说明占位；不自动联网，避免绕过 DSH 会话授权与认证 |
| Markdown 链接 | ◐ | 显示 label 与 URL、下划线样式；未接应用内/外部打开动作 |
| 工具调用卡片、工具参数/结果、子调用树 | ☐ | 审批切片只显示审批卡；工具展示由独立卡片切片负责 |
| thinking/reasoning 展示 | ☐ | 当前只显示 `text-delta`；reasoning 不进入正文 |
| 轮次 token/上下文用量、过程折叠 | ☐ | 官方有轮次用量与过程折叠；原生未接 |
| 复制整条消息、引用/反馈、重试状态行 | ◐ | 代码块可复制、错误时可“重发上一条”；无整条复制/反馈/正式 regenerate |
| 重试/重新生成 | ◐ | 官方未发现独立 regenerate 一元方法；当前“重发上一条”是真实重发，不伪造隐藏重试 |
| 文件引用预览、右侧栏打开 | ☐ | 需文件树/预览切片 |
| 滚动位置恢复、长历史窗口修复 | ☐ | 当前仅 `LazyColumn` 基本滚动 |

## 10. 第一批交付与后续

本 PR（第一批）交付：会话列表/切换/运行状态、历史读取、流式回复、停止、错误展示、审批单次允许/拒绝、提问只读+跳官方、输入/附件/草稿/@/斜杠命令接线、Markdown/代码块/基础表格/图片占位、通知目标与官方回退。

后续建议切片（由编排器决定拆分/顺序）：

1. 会话管理：搜索、新建、重命名、归档/删除、工作区分组、fork/subagent（与 #38 协调）。
2. 消息深度：工具调用卡、thinking/过程折叠、轮次用量、整条复制/反馈、向前分页、链接打开、图片授权加载、正式重试/regenerate（先确认官方方法）。
3. 模型/权限：模型选择、reasoning effort、权限预设、上下文/用量。
4. 工作区：文件树、diff、搜索、预览引用。
5. 设置/技能/插件：主题/字号/语言、链接打开方式、技能列表/启用、插件管理。
6. 设备与真实 PRoot DSH 验收：输入法、附件、审批、通知、远程、安全模式。

未验证边界：本清单的实现状态来自 JVM 协议/解析/控制器测试与编译/lint；真实 Android 设备、PRoot DSH、输入法、图片加载、附件上传、审批 waterfall、通知与远程隧道均未验收。
