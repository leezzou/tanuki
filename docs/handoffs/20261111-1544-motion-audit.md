### 清单记法

源码位置使用 `文件:行`；`U/` = `app/src/main/kotlin/com/tanuki/ui/`，`D/` = `U/design/`，`B/` = `app/src/main/kotlin/com/tanuki/browser/`，`M/` = `app/src/main/kotlin/com/tanuki/`，`R/` = `app/src/main/res/`。末尾有可点击目录入口。

- **F**：`tween` 未指定 easing，使用框架默认 `FastOutSlowInEasing`，不是线性。
- **默认**：调用未给业务 spec，时长/曲线由锁定依赖或系统决定。本轮未读取依赖实现来推定精确毫秒；源码注释中的“300ms”不能代替真实依赖证据。
- **R✓**：有显式 `reducedMotion` 判断或通过公共封装传入 0ms；**R△**：业务未显式处理，依赖系统/Compose 的动画时长缩放，不能据此断言系统关闭动画无效；**R—**：当前无自动视觉动画，暂无降级分支需求。拖动、捏合仍应跟手。
- **0**：直接更新属性或替换内容，无业务过渡；停留 2 秒/3 秒等是反馈保留时间，不是动画时长。
- 清单中的 `S-*` 是下文定义的**拟议语义 spec**，不是当前已有函数；同一行多个位置表示同一交互的同类调用，均在该行建议范围。

## 统一动画方案

### 一套令牌，语义 spec 统一使用方式

沿用 `D/TanukiTokenSpec.kt:129` 的令牌入口，不另建并行设计体系。当前令牌只有名称/时长/类别；拟补曲线、幅度和语义工厂到 `U/TanukiMotion.kt`。`tanukiToggleSpec` 当前仅有定义、没有业务调用，不能只改它就宣称完成全局替换。

| 时长档 | 拟议 token / 保留映射 | 用途与理由 |
|---|---|---|
| 0ms | `instant`；系统移除动画覆盖所有有限动画 | 恢复历史锚点、直接手势、权限生效、不可见状态初始化；避免人为等待 |
| 100ms | 保留 `pressIn` | 按下反馈及图标旧态退出，手下立即有响应 |
| 140ms | 保留 `pressOut` | 松手回位与小反馈退出，比按下略柔和 |
| 160ms | 保留 `toggle` | 颜色、图标、新消息提示、复制、局部状态交叉淡化；高频状态不拖慢操作 |
| 240ms | 保留 `sheetDismiss`；新增语义别名 `layout` / `listMove` / `dock` | 局部尺寸、列表移动、停靠区、普通面板收起；沿用已有停靠条240ms，无需改变其布局契约 |
| 280ms | 保留 `sheetOpen` | sheet / 抽屉打开、大型面板打开；大面积移动需要可辨识过程 |
| 300ms | 保留 `expand` | 只给较长的用户主动详情展开；普通短区用240ms，避免一律慢展开 |
| 320ms | 保留 `page` | 原生层级页面前进/返回、引导步骤；只在结构变化时用 |
| 340ms | 保留 `pageMax`，作为上限 | 后期共享元素或容器转换的上限，常规页面无需使用 |
| 2400ms完整周期 | 保留 `ambientPulse`；`ambientShimmer` 暂不接线 | 真实运行状态点/流式光标低频呼吸；两次1200ms反向为完整周期，无任务不循环，不为统一而新增 shimmer |

现有 `TanukiDesignTokensTest.kt:186`、`TanukiPageVisualsTest.kt:57` 锁定反馈≤160ms、结构240–340ms、环境约2400ms；保留这些范围。`DshDockLayoutTest.kt:170` 锁定200–300ms，240ms别名保持兼容。未来新增语义别名时不可因重复收录而改变现有枚举/计数测试预期，工厂测试应验证解析结果。

| 曲线档 | 明确值 / spec | 使用原则 |
|---|---|---|
| `enter` | `CubicBezierEasing(0.2f, 0f, 0f, 1f)` | 新内容进入，前快后缓；与当前 `tanukiEnter` 一致 |
| `standard` | `CubicBezierEasing(0.4f, 0f, 0.2f, 1f)` | 颜色/尺寸/位置状态之间的连续变化；把当前默认F写明确 |
| `exit` | `CubicBezierEasing(0.4f, 0f, 1f, 1f)` | 内容离开；短于进入，不让退出拖住下一步 |
| `linear` | `LinearEasing` | alpha低频呼吸、真实进度显示的短平滑；不用于整页位移 |
| `settle`（仅手势释放） | `spring(dampingRatio=1f, stiffness=500f)`；reduced时 `snap()` | 无回弹超调，连续速度自然收敛；不是固定时长。只用于手势接续，普通点击不用spring |

幅度统一：局部入场 `translationY=8dp→0`；原生层级前进/返回 `±16dp→0`（RTL 反向，不横穿全屏）；按压 `1→0.98→1`；小图标/确认层 `0.92→1`；alpha `0→1`。导航镜片按实际槽位移动；sheet/抽屉按实际尺寸移动，这两者属于空间关系例外，不把全高滑入错误替换成8dp。没有交互含义时不叠加旋转、模糊、弹跳；镜片减少形变至 `scaleX/Y≤1.02`，reduced 时始终1。

### 每类过渡用哪一档

下表冻结提议值，后续实现者可以直接按名做工厂；若系统公开 API 不支持传 spec，保留系统行为并登记例外，不能修改依赖内部字段。

| 语义 spec | 参数与应用范围 | reduced-motion 与为什么 |
|---|---|---|
| `S-toggle` | `tween(durationMillis = 160, easing = standard)`；颜色、圆角、箭头（保留语义0↔90°/180°） | 0ms；属性保持目标态，不延迟状态 |
| `S-press` | 按下100ms standard / 松手140ms enter，scale0.98；保留原生 ripple | reduced 时 scale固定1，而非0ms跳到0.98；系统反馈不重复叠加手造 ripple |
| `S-icon` | 新图标 alpha+scale0.92→1：160ms enter；旧图标 alpha退出100ms exit；无位移；`SizeTransform`禁用或显式0ms | 所有属性0ms；固定36dp键位，避免默认spring撑长整个 AnimatedContent |
| `S-state` | 固定内容区域内 Crossfade160ms standard，包含真实内容；不加尺寸/位移补间 | 立即替换；避免加载/错误/空态改变容器高度；旧数据可用时不隐藏 |
| `S-page-peer` | 同级原生页 alpha160ms standard，保持宿主尺寸；不移动整页 | 立即切页；同级目的地不暗示层级方向；不可包围活WebView |
| `S-page-depth` | 原生子页进入320ms enter +16dp→0、alpha0→1；返回240ms exit反向，支持RTL | 立即切页；只有层级变化需要方向，不能与子级 `tanukiEnter` 同时播 |
| `S-chrome` | 主动显隐顶/底栏：240ms standard，单一高度或位移所有者；小悬浮按钮alpha160ms enter/140ms exit | 立即切换；IME驱动由系统inset同步，不用自己的240ms追赶键盘 |
| `S-sheet` | 自定义sheet打开280ms enter、关闭240ms exit，全高位移；遮罩160ms standard；只保留一次alpha | reduced全0；退出期间保留最后一份内容快照，结束才卸载；系统sheet保留系统所有者 |
| `S-dialog` / `S-menu` | 系统窗口保留默认和返回/焦点行为；自定义内容若可独立控制，用alpha160ms、scale0.92→1；退出140ms | 自绘内容0ms；系统窗口遵循平台设置并由QA验证；不在系统动画外再套同类scale/fade，不把窗口确认层降成页面内Box |
| `S-expand` | 短区高度240ms standard；长用户详情打开300ms enter/收起240ms exit，alpha160ms；顶端对齐裁剪 | reduced0；只有一个高度动画容器；很长diff先限高/虚拟化，禁止整页 `animateContentSize` |
| `S-dock` | 高度240ms standard、alpha160ms；三条显隐、+N、内部展开共享策略 | reduced0；容器与槽位/子内容不能重复补间同一高度；固定输入栏，维持聊天锚点 |
| `S-input-size` | 行数变化尺寸240ms standard；圆角独立 `S-toggle`，可重定向到最新高度 | reduced立即；只包输入胶囊，不包附件+停靠条+整页，IME不加入该动画 |
| `S-list` | Lazy item `placementSpec=tween(durationMillis = 240, easing = standard)`；新增 `fadeInSpec=tween(durationMillis = 160, easing = enter)`；删除 `fadeOutSpec=tween(durationMillis = 140, easing = exit)` | reduced所有spec置null/立即；只用于稳定key的文件/会话/浏览器管理列表；搜索连续过滤可只淡化，无每项级联 |
| `S-message` | 新到达已提交消息仅alpha160ms，保留稳定key；历史恢复、分页头插、流式delta无入场补间 | reduced立即；不对历史 `placement`，不逐字动画，不重播流式气泡 |
| `S-count` | 固定最小宽度，数字alpha160ms、无滚轮/垂直滑动 | reduced立即；数量/高风险标志的语义与可操作性立即更新，不等上一数字退出 |
| `S-copy` | 固定宽度文案/图标交叉淡化160ms，确认态1500ms后复位；重复点击重置截止时间 | reduced仍保留确认文字，0ms切换；停留时间用无障碍推荐超时适配，不能把“无动画”当“无反馈” |
| `S-progress` | 确定值可选100ms linear朝真实新值重定向；任务id/阶段变化立即复位；未知总量保留系统不定进度 | reduced确定值立即、未知值改静态标识+真实阶段/耗时；不造百分比、不给网络动作加最短动画等待 |
| `S-scroll` | 用户主动短距定位240ms standard；长距先无动画定位邻近目标再短距，Lazy API不支持spec时保留默认并测量 | reduced用 `scrollTo/scrollToItem`；历史锚点恢复永远立即；双轴搜索可并行滚动，避免先竖后横 |
| `S-zoom` | 双击/按钮缩放240ms standard，围绕目标中心同时变scale/pan；直接捏合/平移0ms | reduced跳到目标但保留手势；不每帧重解码，不重排整份大文档 |
| `S-window` | 应用内小窗收起/展开280ms enter / 240ms exit，保持顶边锚点；拖动0ms、边界回位settle | reduced0；系统悬浮窗跨窗口/重parent需要单独验证，禁复制活WebView |
| `S-fullscreen` | 同一内容实例：原生chrome240ms，系统栏由系统控制；必要占位alpha160ms，提交一次最终视口 | reduced立即；先保证视频播放位置、阅读缩放/锚点，再考虑容器动画；Surface视频不做整体scale |
| `S-reduced` | 一处状态来源，首次读取系统开关；监听或回到前台刷新，主题和非Compose窗口共用策略 | 关闭循环；按压/镜片不形变；有限动画0ms；系统组件按公开机制验证；不改用户系统设置 |

### 生命周期与可访问性约束

1. 当前 `rememberTanukiReducedMotion()` 只是组合时调用 `ValueAnimator.areAnimatorsEnabled()`，不是订阅；不能保证用户在系统设置切换后立即刷新。未来在 `TanukiDesignTheme` 接入可观察来源/生命周期刷新，异步回到前台时同步最新值；非Compose悬浮窗读取同一策略。Compose系统时长缩放仍保持，不重复手动按缩放倍率延长时长。
2. 退出动画必须保留组件与内容到过渡结束。`TanukiBottomSheet` 目前可见性宿主仍在，但 `FailureDetailSheet` 的 `failure?.let` 会立即清空内容；`DshDock` 在goal/todo变null时同样可能只有空槽退出。后续只缓存可公开展示的最后一份UI模型，不缓存凭据；交互、权限与业务状态立即按真实状态关闭。
3. 快速反复触发只重定向当前动画，不排队补播。切换会话/目录/主机必须按稳定身份取消旧任务，防止旧动画终点覆盖新界面。
4. reduced-motion时循环不创建；空闲/后台/离屏也不创建装饰循环。当前状态点和光标已按条件停止，保留该实现。`ambientShimmer`仅定义；`TanukiStreamingCursor`未接原生聊天，不把“已有组件”写成“用户已看到”。
5. 启动、回到前台、旋转和历史恢复不重放整页入场。初始内容立即可用，不用alpha0等待业务异步完成。屏幕阅读焦点、按钮enabled、风险说明、取消动作不随视觉退出继续有效。
6. WebView不得被整页 `graphicsLayer`/共享元素层录制，不截图复制敏感登录页，不重复创建两个活网页。只动画原生chrome/遮罩/非敏感占位；`pauseTimers()`不作为动画或省电手段。

### 不适合“全局替换”的位置

- 不把 `spring(` 全部替成 `tween`：拖动释放需要速度连续；默认系统drawer/sheet/控件由平台拥有，公开API不支持时保持默认。
- 不把所有 `scrollToItem` 改成动画：聊天头插恢复、窗口释放和会话切换的定位必须立即；自动流式跟随不排动画队列。
- 不对所有Lazy行加 `animateItem`：聊天历史、连续筛选、换目录跨数据集应分开；文件重命名path会变，需要临时操作身份才能避免被当成无关删增，第一批可仅淡化该操作。
- 不给 `AnimatedVisibility` 外再包 `animateContentSize`：先认定谁控制高度。停靠条内部有多层条件数据，移除一层时需覆盖“整条出现/内部展开/数据终态删除”三类，不能凭少一个API就宣称正确。
- 不用动画掩盖加载慢、未知状态或请求失败；不新增最短等待，3秒审批提示/2秒notice/1500ms复制是反馈停留语义，与动画token分开。
