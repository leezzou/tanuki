### VQ-01 · P1 · 新提问卡未接入生产聊天，回答状态仍是开发占位

- 截图：**S06**（合成组件证据，非真实事件触发）。
- 复现：在 Android 中以 `DshQuestionCard(request)` 的默认参数挂载一个必填单选问题，选项为“配色与可读性 / 聊天布局”，不提供产品当前未接线的 `onSubmit/onSkip`。当前 `app/src/main` 对 `DshQuestionCard` 只有定义，无生产调用点；`DshNativePage` 也没有挂载该卡。
- 期望：原生聊天收到提问后出现新卡片，可选择并提交；若暂不支持，应提供可操作的官方界面入口与中文说明。
- 实际：组件可画出，但生产聊天没有接入点；默认卡出现“本地选择 · 回答接口待确认”“待协议确认”，不回答/提交均不可用，无可完成动作。
- 定位：`ui/DshQuestionCard.kt:43–55,75–105`；`ui/DshNativePage.kt`；`web/DshQuestion.kt`。已有协议未完成限制，不作为本轮新回归。**真实 `user-questions/request` 事件及官方回答 RPC 未执行**；本结论由组件设备画面与调用点核对共同支持。
