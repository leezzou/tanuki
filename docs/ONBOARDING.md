# 首次启动与准备

首次启动只展示运行位置选择与本机准备两屏。准备页与设置安装入口共用实际组件、运行状态和进度，界面偏好不再作为必经步骤。

## 主路径

- 欢迎页说明手机运行与联网模型的关系，主动作进入本机准备；远程连接直接可用，无需先下载本机组件。
- 本机准备页首先展示当前状态与一个主动作：开始准备、重试、启动助手或进入对话。设备阻止项直接给出原因，正常设备参数折叠查看。
- 准备复用既有 `INIT` 链路，自动检查并补齐系统、运行组件、基础工具与助手。组件版本、下载源、逐项重装/卸载保留在“组件与下载设置”。
- 运行组件完整且工具检查对应当前系统版本、环境为 READY 才算准备完成；不能用 Ubuntu 单独 READY 判断整个流程结束。
- 助手启动与安装分别展示。用户点击“启动并进入对话”后，只有服务 RUNNING、健康端点可用、对话连接就绪且网页支持门控允许时才自动进入；失败停在原页，离页会丢弃自动进入意图。已运行时可直接“进入对话”，连接不可用时提供检查入口。进入对话不宣称模型账号已配置。
- 网页与手机界面选择放在“界面偏好”展开区，仍可在设置 → 引擎与更新 → 网页与兼容性切换。

## 进度与恢复

`Snapshot.operationActive` 决定当前是否仍有操作；`timing` 提供单调时钟的开始/最近活动时间。未知总量显示不定进度，已知总量只计算当前阶段比例，不显示虚构的整体百分比或线性完成刻度。下载有有效总量与速度样本时才估算本次下载剩余时间；无样本不承诺几分钟。

当前阶段、耗时和一分钟无新进展的提醒直接放在准备页。后台继续与停止准备是不同动作：离开页面不取消工作；停止只在当前后端允许取消时显示。启动或事务切换等不支持取消的阶段不显示停止按钮。

失败原因就地显示，技术原文默认折叠。重试优先携带原失败操作的标识；需要重新选版本或下载源时进入组件维护，不把卸载/切换失败转换为全新安装。取消后重新准备会检查并复用可用组件与下载。

## 首次、升级与旧记录

引导记录仍保存在独立 `onboarding` SharedPreferences，原 WELCOME/ENVIRONMENT/INTERFACE/DONE 存储值不变，不重置已有进度。

| 状态 | 行为 |
|---|---|
| 从未打开 | 展示欢迎页 |
| 未完成且未跳过 | 从持久化未完成处恢复；旧界面选择/完成页映射为准备页 |
| 主动稍后设置/后台继续 | 关闭引导，首页保留可关闭的恢复入口 |
| 已完成 | 同版本线不重播；设置仍可重新打开 |
| 大版本线升级 | 一次可关闭的轻提示 |
| 覆盖升级且没有引导记录 | 视为已有安装，不强制重播 |

欢迎页返回可退出，准备页返回上一页；系统返回不取消实际安装。准备完成后的进入对话和远程入口均沿用宿主导航回调。

## 设备与权限

本机要求 ARM64、Android 8.0+、至少 2 GB 内存及 1.5 GB 可用存储，建议 4 GB 内存与存储。阻止项不允许新建本机准备，但允许连接远程电脑。已有操作不因页面重新检测而被取消。

只有用户点击开始准备时才申请通知权限，用于后台进度；拒绝仍可准备。读取共享存储的权限仍在实际浏览文件时按需申请；进入引导、进入聊天和远程连接不一次性申请额外权限。

## 实现与验证边界

- `ui/SetupJourneyPresentation.kt`：完整组件与服务状态的纯展示决策。
- `ui/SetupJourney.kt`：两处入口共用的准备、耗时、进度、失败与依赖清单。
- `ui/OnboardingScreen.kt`：两屏引导、设备明细及界面偏好。
- `ui/SetupScreens.kt`：准备概览和原组件维护入口。
- `onboarding/OnboardingModel.kt`、`OnboardingController.kt`、`OnboardingStore.kt`：原记录与门控；保留旧存储兼容性。
- `ui/OperationProgressPresentation.kt`：真实阶段、取消能力、失败操作与耗时，准备页复用其模型。

JVM 定向回归包含 `SetupJourneyPresentationTest`、`OnboardingFlowTest`、`OnboardingEnvironmentTest`、`OnboardingPrepareTest` 与进度回归。实际命令和本轮结果记录在本次交接；源码中存在测试不代表已经在设备上执行。

设备首启/真实下载、权限拒绝、离页返回、取消重试、启动失败恢复、深浅色/大字号/TalkBack与真实模型均需独立 Android 验证。宿主 compile/JVM/lint 不能替代设备验收；API Key保存暂停项不在本次范围。
