# 项目空间与容量预算

Ubuntu 中的 `/workspaces` 对应 Android 应用私有目录 `files/workspaces`。当前开发包为 `com.tanuki.modern.workspacecheck`，实际位置通常是 `/data/user/0/<applicationId>/files/workspaces`，以构建包名为准；默认 DSH 项目位于 `/workspaces/deepseek-harness/default-workspace`。

这里使用手机已有的文件系统，没有单独创建固定大小的虚拟磁盘。容量预算是应用提供的软上限，不能扩大手机的物理存储，也不会预先占用所填空间。

应用内文件页支持在 DSH 运行中浏览目录、查看文件、导入到新独立项目，以及导出单个文件或整个工作区。新建、编辑、复制、移动、重命名和删除等修改已有目录的操作仍需先停止 DSH。导入不会覆盖原项目；运行中导出逐文件核对身份、大小和修改时间，读取期间发生变化会失败并尝试删除未完成的目标文件。整个工作区不是同一时刻的原子快照；需要一致备份时可先停止任务。

顶部「＋ 导入」直接打开系统多选，更多菜单中对应「导入为新项目」。后台按 64 KiB 分块读取手机/SAF 文件，写入独立暂存项目并回读 SHA-256 校验，主线程只负责界面。单文件用源文件名去掉最后一个扩展名作项目目录（如 `合同.pdf` → `合同`），多文件用 `导入-yyyyMMdd-HHmm`；项目名冲突追加 ` (2)`、` (3)`，保留原有项目。同批同名文件在扩展名前加序号（如 `合同 (2).pdf`）。路径分隔符、控制字符等不安全字符会被清洗，长 UTF-8 名称按完整字符截断并尽量保留扩展名。

只有所有文件都返回有效大小时才显示真实百分比，任一大小未知就显示不定进度，不估算总量。进度更新按时间间隔合并，不会按 64 KiB 分块刷新整页；文件列表在排序/刷新期间保留旧条目身份，也在切换目录时清空。进度详情里可取消本次文件任务（包括等待网页回包的 Blob 导出）：取消清理本次未提交的暂存，保留原项目；如果导出/下载已向手机存储创建目标文件，取消或失败时尝试删除本次未完成目标，删除失败会提示检查。导入成功会立即刷新文件列表并显示「已导入 N 个文件到「目录」」及「打开」；列表顶部保留一次性「刚刚导入：目录」与「打开 / 忽略」入口。点「打开」清除搜索并进入新项目目录，查看器内发起的显式复制也可打开目标。

「手机存储」显示内部共享存储与系统可用的 SD/USB 卷。Android 11 及以上点击「授权访问手机文件」进入本应用的“所有文件访问”设置；返回后刷新授权状态。Android 8–10 请求存储读取权限。授权可在系统设置撤销；其他应用私有数据和 Android 限制目录仍不可访问。文件页可浏览、导出和显式复制/移动到工作区；这些操作不自动把共享存储挂载给 DSH，也不授予 DSH 或浏览器 AI 写权限。

## 手机存储复制与移动到工作区

在手机卷内条目菜单或多选批量条选择「复制到工作区 / 移动到工作区」，默认目标是最近停留的工作区目录，可进入或返回目录修改。存储卷根和链接不能作为传输源。移动需要系统写权限；Android 8–10 在单独确认后申请写权限，Android 11 及以上复核所有文件访问权限。目标确认明确说明移动会在副本校验成功后删除手机源文件。复制/移动要求先停止 DSH，以避免同时修改工作区。

遇到同名普通文件可选「保留两者 / 替换 / 跳过」，默认保留两者，序号放在扩展名前；同名文件夹、链接或不同类型条目不提供替换。勾选「全部应用到这个批次」只作用于尚未处理的冲突，已单独选择的策略保留。替换在完整副本校验通过、原目标版本未变化时才执行。批量部分失败会保留已完成项并列出未完成项，跳过项不复制也不删源。

传输显示统计、复制校验、源文件/容量复核、提交/清理等真实阶段与耗时，并复用传输胶囊显示字节进度及取消。每项先复制到目标目录的隐藏暂存，再核对长度、回读摘要与源清单，并在发布前复核容量预算和系统授权；移动还重新读取源摘要。发布前失败或取消只清理该项暂存，源文件和原目标保留。发布后只删除本次已校验的源条目，后来新增的条目不会被递归删除；删源失败保留已校验目标并提示检查源。目录复制拒绝符号链接、特殊文件和超过 128 层的目录。外部应用仍可并发改写手机文件，用户应在移动前停止其他写入任务。

外部 `content://` 查看仍直接读取提供方，只有主动选择导入/复制才落入工作区，不强制先复制再查看。

## 文件页信息层级

文件页顶部主操作行最小 56dp：位置选择、填充色「＋ 导入」、更多和最右侧的「只读/可写」权限 chip。搜索、刷新、排序与显示收进更多菜单；空目录以文件夹图标和说明提供「从手机导入 / 新建文件夹」双按钮；DSH 运行时保留导入并禁用新建文件夹。空目录导入期间显示真实字节进度行与取消，完成后沿用导入事件刷新及「打开」反馈。第二行按上下文切换为搜索框、批量选择操作或可横向滚动的面包屑。权限 chip 打开底部 sheet，集中放置手机存储授权、本次 DSH 写入授权/撤销、工作区写入暂停说明和停止 DSH；列表页不常驻权限说明卡。导入结果的一次性入口与手机传输的阶段/耗时仅在相应事件发生后出现。

文件复制、导入或导出时，右下角悬浮胶囊显示进度环、百分比和取消入口；没有传输时胶囊完全不出现。点击胶囊打开底部 sheet，逐项显示文件名、实际字节/总大小、百分比、剩余时间估算和单文件取消。总大小未知时使用不定进度，不估造百分比；剩余时间只在已用时间与已接收字节足够估算时显示。全局安装进度以导航上方细条浮层展示，点击展开阶段与耗时抽屉，不参与页面测量；文件页继续使用自己的传输胶囊，不在全局浮层重复文件任务。

搜索时选中文件后，第二行切换为批量操作并保留当前筛选条件，“全选”只作用于匹配结果。列表和文件查看器共用同一个传输浮层；从查看器导出或复制到工作区后，进度胶囊和取消入口仍留在当前页面。查看器底部操作栏可见时，胶囊在导航 inset 之外再叠加 48dp 操作栏高度与 12dp 间距，避免遮住“导出此文件”“复制到工作区”等按钮；列表页和全屏阅读仍只保留 12dp 间距，不新增固定块。列表占满剩余高度，底部预留固定避让空间给悬浮胶囊；进度帧只在浮层内订阅，权限 chip 的只读/可写切换也不改变列表测量。搜索/排序等列表加载使用叠加的 2dp 指示线，不插入布局。错误和操作反馈改用 Snackbar，不再新增固定提示块。所有主要触控入口至少 48dp，并沿用主题色以适配深色模式。

上述布局、360dp 窄屏、大字体和深色模式只完成源码结构与 JVM 状态/格式化回归，未在模拟器或真机验证；设备视觉、手势、滚动锚定与 TalkBack 仍待独立 QA。

文本查看器按 64 KiB 分段读取，提供等宽字体、可开关行号、当前段搜索/匹配跳转、只读选择复制、字号、换行及编码选择。自动识别顺序为 BOM（UTF-8/UTF-16LE/BE/UTF-32）→ UTF-8 严格校验 → 无 BOM UTF-16 启发式 → GB18030（覆盖 GBK/GB2312）→ Big5 → Shift_JIS → Latin-1 兜底；识别不到或字节不合法时仍以兜底编码显示，不会把“无法解码”抛给用户，并在顶部提供可关闭提示和 UTF-8/GB18030/UTF-16/Big5/Latin-1 手动切换。空字节或控制字符比例超阈值的内容显示“这是二进制文件”，只保留“用其他应用打开/复制路径”，不进入文本视图。查看不再受编辑器 256 KiB 上限约束，但单次查看最多显示 4 MiB，达到上限后停止翻页并提示已截断，可导出或用其他应用打开完整文件。扩展名与 MIME 由 [`FileTypeCatalog`](../app/src/main/kotlin/com/tanuki/storage/FileTypeCatalog.kt) 集中维护：C/C++/头文件、Java/Kotlin/Python/JS/TS/Go/Rust/Shell、JSON/XML/YAML/TOML/INI、Markdown/纯文本/日志、HTML/CSS/SQL/CSV、SVG，以及 `.env`/`.env.*`、Dockerfile、Makefile 等已知配置按文本只读打开；`.DS_Store` 等隐藏二进制仍走未知类型回退；扩展名优先于系统 MIME，避免 `.ts` 被当作 MPEG-TS 视频。未知或暂不支持的格式显示中文说明，并提供“用文本打开/复制路径”回退。图片、PDF、DOCX 与 XLSX 可内置只读预览；XLSX 使用原生表格显示多工作表、冻结窗格、合并单元格与基础样式，不还原图表、宏、透视表、外部链接和复杂条件格式，也不重新计算公式。音频和视频使用系统原生解码播放，也可选其他应用打开；旧版 `.doc`、`.xls`/`.xlsm`、压缩包等提供系统应用打开入口，实际可打开格式取决于已安装应用和设备解码器；未知格式可尝试按文本查看。

目录浏览、工作区导出和默认容量统计不设固定文件数量上限，列举/排序在后台进行，列表按需绘制；仍受设备内存、磁盘与统计耗时约束，不承诺无限资源。原有容量预算、64 MiB 设备余量和单次导入 512 MiB 的字节限制保留，文件数量与字节容量是不同边界。

本轮之前文件页连浏览/预览/传输也要求停止DSH；该旧策略已被读写分离替代。此前咨询只有静态核对，不计本轮产品测试。

## DSH手机文件权限

原生文件页把所选文件的逻辑工具路径（如`/phone/primary/Download/example.txt`）复制给DSH；它不是可直接`cat`的Linux挂载路径。DSH通过随附的`tanuki-phone`技能和`node /opt/tanuki-phone/tanuki-phone.mjs`客户端访问。启动DSH时只绑定私有工具目录，真实共享卷不直接暴露给客体；不修改官方DSH包或其审批/沙箱设置。旧的运行进程需在任务结束后手动重新启动一次以加载新工具；后续原生写授权不需要重启。

系统存储访问权限授予后，手机文件工具默认允许浏览、stat和分段读取，**写权限默认关闭**。打开「文件 → 手机存储 → 授权DSH写入」，明确确认「允许本次写入」后才允许创建、修改、重命名与删除（只删除文件/空目录）。可以随时点「撤销DSH写入权限」，停止或重启DSH也会恢复只读；工具请求不能自行授权。Android8–10在此独立步骤请求WRITE_EXTERNAL_STORAGE，普通读取步骤只请求READ；Android11+即使系统MANAGE已允许写入，仍需本应用的本次写许可。

每次写入、上传分块及提交重新检查系统权限、原生授权和授权代次；撤销后旧上传不能提交。覆盖已有文件必须携带当前内容版本，内容已变化则拒绝，不自动刷新版本重试覆盖。上传先写私有暂存区，再在提交时检查目标/版本和许可。路径穿越、符号链接、卷根改动及Android/data、obb、sandbox等专属目录被拒绝。接口是本机连接能力，不隔离持有同UID的恶意代码；不得据此关闭DSH官方审批。

视频查看器点开后在后台提取封面，支持拖动进度、前后10秒、0.5/0.75/1/1.25/1.5/2倍速、播放/暂停及全屏。全屏隐藏应用外壳与系统栏，保持播放器/进度/倍速；返回键先退出全屏，再关闭查看器。切到后台暂停，关闭释放资源。解码/倍速仍取决于设备，失败时提示并保留外部应用打开入口。

## 调整方式

1. 停止 DSH，并等待当前安装、导入或更新操作完成。
2. 打开「设置 → 项目空间 → 调整容量预算」。
3. 选择「跟随可用空间」，或选择「自定容量上限」并输入 GiB。例如 `2` 表示 2 GiB，`0.5` 表示 512 MiB。
4. 点击「保存预算」。现有项目保留，不会为了缩小预算而删除文件。

最小自定预算为 64 MiB（0.0625 GiB），不能小于当前项目占用，也不能超过现有占用加设备当前可用空间减 64 MiB 余量。实际占用尚未成功统计时，可刷新后设置，或先恢复「跟随可用空间」。

界面显示项目实际占用、设备剩余空间和预算内可用量。项目按实际分配的磁盘块统计；稀疏文件的逻辑长度不等于已占用空间，共享同一内容的 PRoot 模拟硬链接不重复计算内容。

## 预算如何生效

- 导入前与导入过程中检查容量；失败或取消时清理本次暂存内容，保留原项目。
- 启动 DSH 前检查当前占用，超额时提示调整预算或清理项目。
- DSH 运行中定期检查；发现超额后停止本次 DSH 进程，可能中断正在执行的任务。
- 连续无法可靠统计时，应用保守停止；不会把未知占用显示为零。

这不是内核强制配额。命令直接写入时可能在下一次检查前超过预算，其他应用也可能消耗同一块存储。Ubuntu、Node、DSH 程序、会话、备份及下载缓存另占空间，不计入项目预算。

## 文件持久化与临时目录

Android 普通应用不能直接使用宿主硬链接。PRoot 保留链接模拟，但新创建的链接内容存入独立的 `files/link-store`，不再随写入工具的临时目录一起删除。备份与项目导出会读取可验证的实际内容，避免只保存指向活动内容库的链接；无法解析的内容会报错，不会当作完整备份。

内容库可能包含多个组件和用户目录的共享文件。项目目录项删除不保证内容库立即释放全部空间；仅在停止运行环境后的受控清理中回收确定无人引用的内容，扫描不完整时不删除。已经丢失的旧内容不会因升级自动恢复。

`/tmp` 映射到专用 `files/guest-tmp`，与 PRoot 自身运行暂存目录分开。`/dev/shm` 映射到私有磁盘目录，可用于需要该路径的软件，但不是内核 tmpfs，也不会提供额外的沙箱能力。

普通文件管理器通常不能访问应用私有目录。项目导出使用 ZIP；目前遇到普通符号链接或特殊文件会明确失败，而不是静默遗漏。卸载整个应用或清除应用数据会删除私有项目；仅重装 Ubuntu 组件会保留它们。
